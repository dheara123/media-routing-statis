Jalur A · Dasar

1. Konsep Dasar Jaringan

Sebelum mempelajari routing statis, pahami terlebih dahulu alamat IP, subnet mask, network address, router, dan default gateway. Konsep ini membantu kamu menentukan apakah dua perangkat berada pada jaringan yang sama atau berbeda.

Alamat IP

Alamat IP merupakan alamat logis yang digunakan untuk mengidentifikasi perangkat pada jaringan IP. Contohnya adalah 192.168.1.10.

Subnet Mask

Subnet mask digunakan untuk menentukan bagian alamat IP yang menunjukkan jaringan dan bagian yang menunjukkan host. Contoh subnet mask /24 adalah 255.255.255.0.

Network Address

Network address mengidentifikasi suatu jaringan. Dengan subnet mask /24, alamat IP 192.168.1.10 termasuk dalam jaringan 192.168.1.0/24.

Alamat IP Subnet Mask Jaringan
192.168.1.10 255.255.255.0 192.168.1.0/24
192.168.1.20 255.255.255.0 192.168.1.0/24
192.168.2.10 255.255.255.0 192.168.2.0/24
Perhatikan perbedaannya.

192.168.1.10/24 dan 192.168.1.20/24 berada pada jaringan yang sama, sedangkan 192.168.2.10/24 berada pada jaringan yang berbeda.

Router dan Default Gateway

Router meneruskan paket antarjaringan. Default gateway merupakan alamat router yang digunakan perangkat untuk mengirim paket menuju jaringan di luar jaringan lokalnya.

Perhatikan contoh jaringan berikut. PC1 dan PC2 berada pada jaringan yang berbeda dan dihubungkan oleh R1 serta R2.

↔
Router R2 Link: 10.10.10.2/30 LAN: 192.168.2.1
↔
PC2 192.168.2.10/24 Gateway: 192.168.2.1

Informasi Jaringan

Perangkat Alamat IP Fungsi
PC1 192.168.1.10/24 Perangkat sumber
R1 192.168.1.1 dan 10.10.10.1/30 Meneruskan paket dari LAN 1 ke jaringan berikutnya
R2 10.10.10.2/30 dan 192.168.2.1 Meneruskan paket menuju LAN 2

Jalur B · Routing

3. Pengertian Routing Statis

Routing statis adalah metode routing ketika administrator memasukkan jalur menuju jaringan tujuan secara manual ke dalam router. Router menggunakan informasi tersebut untuk meneruskan paket ke jaringan yang dituju.

Karakteristik Routing Statis

  • Rute ditentukan dan dimasukkan secara manual.
  • Administrator menentukan jaringan tujuan dan next-hop.
  • Perubahan rute perlu disesuaikan secara manual.
  • Konfigurasinya relatif sederhana untuk jaringan kecil.

Komponen Perintah Routing Statis

ip route [jaringan-tujuan] [subnet-mask] [next-hop]
Komponen Penjelasan
Jaringan tujuan Jaringan yang ingin dicapai oleh paket.
Subnet mask Menentukan cakupan jaringan tujuan.
Next-hop Alamat router berikutnya yang menjadi tujuan penerusan paket.

Contoh Konfigurasi R1

R1 perlu mengetahui jalur menuju jaringan PC2, yaitu 192.168.2.0/24, melalui R2 yang beralamat 10.10.10.2. 

R1(config)# ip route 192.168.2.0 255.255.255.0 10.10.10.2

Contoh Konfigurasi R2

R2 perlu mengetahui jalur kembali menuju jaringan PC1, yaitu 192.168.1.0/24, melalui R1 yang beralamat 10.10.10.1. 

R2(config)# ip route 192.168.1.0 255.255.255.0 10.10.10.1
Ingat:

Jalur pergi dan jalur kembali harus diperhatikan. Konfigurasi rute statis saja tidak menjamin komunikasi berhasil jika alamat IP, gateway, atau koneksi antarrouter belum benar.

4. Pengujian Konektivitas

Setelah konfigurasi dilakukan, periksa tabel routing dan uji keterjangkauan perangkat.

Memeriksa Tabel Routing

R1# show ip route
R2# show ip route

Menguji Koneksi

ping 192.168.1.1
ping 10.10.10.2
ping 192.168.2.10

Pengujian dilakukan bertahap, dari gateway lokal, router tetangga, hingga perangkat tujuan.

Jika ping gagal

Periksa alamat IP, subnet mask, default gateway, status antarmuka, koneksi antarrouter, serta tabel routing. Pertimbangkan juga kemungkinan adanya pembatasan ICMP.

5. Pemecahan Masalah Jaringan

Gunakan urutan pemeriksaan yang terstruktur agar kamu dapat menelusuri kemungkinan penyebab gangguan.

1

Identifikasi gejala

Catat perangkat mana yang tidak dapat berkomunikasi.

2

Periksa konfigurasi dasar

Periksa alamat IP, subnet mask, gateway, dan status antarmuka.

3

Periksa jalur routing

Pastikan jaringan tujuan dan next-hop sesuai dengan topologi.

4

Uji kembali

Gunakan ping dan periksa apakah komunikasi sudah berhasil.

Jalur C · Penguatan

6. Bantuan Istilah

Buka istilah yang ingin kamu pahami kembali. Kamu tidak harus membuka semuanya.

Apa itu network address?

Network address merupakan alamat yang mengidentifikasi suatu jaringan, misalnya 192.168.1.0/24.

Apa itu next-hop?

Next-hop merupakan alamat router berikutnya yang digunakan untuk meneruskan paket menuju jaringan tujuan.

Apa itu default gateway?

Default gateway adalah alamat router yang digunakan perangkat untuk mengirim paket menuju jaringan di luar jaringan lokalnya.

Apa perbedaan routing statis dan dinamis?

Pada routing statis, rute dimasukkan secara manual. Pada routing dinamis, router menggunakan protokol routing untuk mempelajari dan memperbarui informasi rute sesuai mekanisme protokol yang digunakan.

Mengapa diperlukan rute balik?

Komunikasi dua arah memerlukan jalur untuk paket pergi dan paket balasan. Jika jalur kembali tidak tersedia, komunikasi dapat gagal meskipun paket pergi berhasil.

Sudah lebih paham?

Kembali ke topologi atau contoh konfigurasi, lalu periksa apakah kamu dapat menjelaskan fungsi setiap alamat dan jalur yang digunakan.

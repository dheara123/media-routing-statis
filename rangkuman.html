Rangkuman Routing Statis

Gunakan rangkuman ini untuk mengingat kembali konsep inti atau langsung kembali ke bagian yang ingin kamu pelajari.

1. Konsep Utama

Konsep Ringkasan Pelajari Lagi
Alamat IP Alamat logis perangkat dalam jaringan IP. Buka dasar
Subnet mask Menentukan bagian jaringan dan host dari alamat IP. Buka dasar
Router Meneruskan paket antarjaringan berdasarkan informasi routing. Buka topologi
Routing statis Rute dimasukkan secara manual oleh administrator. Buka routing
Next-hop Alamat router berikutnya untuk meneruskan paket. Buka bantuan
Pengujian konektivitas Memeriksa keterjangkauan perangkat dan jalur komunikasi. Buka pengujian

2. Ingat Urutan Konfigurasi

1

Periksa alamat IP

Pastikan alamat IP dan subnet mask sesuai topologi.

2

Periksa koneksi antarrouter

Pastikan antarmuka dan jaringan penghubung berfungsi.

3

Tambahkan rute statis

Tentukan jaringan tujuan, subnet mask, dan next-hop.

4

Periksa jalur balik

Pastikan router tujuan memiliki jalur kembali jika diperlukan.

5

Lakukan pengujian

Periksa tabel routing dan uji konektivitas secara bertahap.

3. Contoh Perintah

Rute pada R1 menuju jaringan PC2:

R1(config)# ip route 192.168.2.0 255.255.255.0 10.10.10.2

Rute balik pada R2 menuju jaringan PC1:

R2(config)# ip route 192.168.1.0 255.255.255.0 10.10.10.1

Memeriksa tabel routing:

show ip route

Menguji konektivitas ke PC2:

ping 192.168.2.10
